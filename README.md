# Exploratory Data Analysis of the UCI Heart Disease Dataset

## Overview

This is my first personal data science project using the UCI Heart Disease dataset. As a UCI alum and a telemetry technician with three years of experience monitoring cardiac patients, I was interested in exploring a dataset related to cardiovascular health.

The goal of this project was to practice data cleaning, exploratory data analysis (EDA), and data visualization while investigating factors associated with heart disease severity.

Using Python, Pandas, Seaborn, and Matplotlib, I analyzed demographic characteristics, symptoms, and clinical measurements to identify patterns associated with heart disease severity.

The dataset contains demographic information, symptoms, clinical measurements, exercise stress test results, and heart disease diagnoses for 920 patients. The goal of this analysis was to identify meaningful patterns in the data through exploratory data analysis (EDA).

## Questions Explored

Q1: Does heart disease severity differ between males and females?
Q2: Which chest pain types are most strongly associated with heart disease?
Q3: Is exercise-induced angina related to heart disease severity?
Q4: How does heart disease severity vary by ST segment slope?
Q5: Which clinical measurements appear most strongly associated with heart disease severity?
Q6: Which numeric variables exhibit the strongest relationships with heart disease severity?

## Key Findings

- Male patients showed higher average heart disease severity than female patients.
- Asymptomatic chest pain was associated with the highest average heart disease severity.
- Patients with exercise-induced angina tended to have substantially more severe heart disease.
- Oldpeak showed one of the strongest relationships with heart disease severity.
- Maximum heart rate generally decreased as heart disease severity increased.
- Exercise stress test variables appeared to be more informative than cholesterol and resting blood pressure in this dataset.

## Limitations

- Several variables contained substantial missing data and required imputation.
- The dataset was heavily skewed toward male patients.
- This project focused on exploratory analysis and does not establish causal relationships.
